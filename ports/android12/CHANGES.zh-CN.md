# 现代服务运行时与多版本并行验证（2026-10-06）

- 新增在 IWLAN APK 的实际声明库类加载器内执行的 root 诊断入口，以及独立
  root helper；区分应用进程的 IKE／EAP 库可见性和 root 框架接口可见性。
- 实际核对系统／特权安装、权限、服务声明、Binder 描述符与存活状态。
  绑定后释放连接；root 与特权非 root 调用分别验证，没有绕过 DATA／NETWORK
  的平台签名权限。额外声明 IMS 绑定权限，仅供本研究入口的 IMS 连接检查。
- 新增有界、模拟器专用的 QNS 临时选择试验，要求单个非 VOXI 测试订阅；
  `persistent=false`，在 `finally` 清除覆盖，核对整个原配置恢复且无持久文件。
- 两个独立 agent 同时验证 Android13／API33 与 Android16／API36，均通过权限、
  20 项声明库查找、IWLAN／IMS 连接、调用者隔离和 CarrierConfig 读取。
  随后并行补测系统电话进程 QNS 绑定，两者均通过并完整恢复配置。
- Android12 的前期模拟器检查通过；12L／14／15 尚只有静态检查。17 仅为
  固定 Robolectric 样本检查，本次官方 SDK 列表未提供对应镜像，未声称运行支持。
- 测试报告按版本隔离，失败明确写 `failed` 并清理旧原始结果；保留每个版本的
  安装摘要和安全诊断记录。新增构建输出文件的路径别名检查。
- 当前 API30 手机仍用工具0.8.0／模块0.9.0，本批没有改手机。现代生产安装器／
  控制器、真实运营商注册／通话短信／双活动 SIM 仍需验证。

- 新增 `build-services.py`，实际编译 API31 IWLAN／QNS／IMS 三个 APK；
  QNS、IMS 使用独立 SDK31 manifest 和现有授权／订阅／状态代码。

  API31 输出选择，拒绝目录别名。构建前后核对整个 API30 输出和上游源码，

- 产物为未签名研究包，包含实际 APK、摘要、框架来源、许可证和第三方说明。
  没有安装器／启动脚本，未装到手机，也未开放应用的现代替换入口。
- 新增编译产物检查：三组件角色、SDK31、编译后服务声明／intent／绑定权限／
  导出属性、状态入口和 IKE 库、IMS 三个订阅接口、精确归档和
  许可证一致性通过。251 个框架引用、21 个 Android 派生类，在七份固定
  Android12／12L／13／14／15／16／17 样本无缺失或生命周期问题。

  15 项契约检查通过，隔离编译的新 helper 在现有 API30 手机只读查询通过。
  当前在机模块 helper 未更新；现代 Binder 权限尚无实机证明。
- 现代 IWLAN 60 项受控契约及 API30／API31 类型隔离检查通过。上述检查
  不能证明现代安装／权限／IKE／实际通话短信／双活动 SIM／长期稳定性。
