## 续批：现代订阅配置持久化与恢复

- 核对 AOSP Android12／13／16 的具体发布版本：持久与临时覆盖是两个层，
  文件通过平台 PersistableBundle 流接口序列化，写入／删除是异步流程。
- 新增现代 CarrierConfig 事务层，复用订阅身份与原文件备份机制，按明确
  slot／sub 及组件掩码选择，双重核对实时配置和落盘值，恢复后比较完整原配置。
- 恢复新增 FILE_RESTORING 阶段，避免恢复原文件后异常退出，重试又清除原文件。
  已恢复阶段支持重复核验；未完成准备的状态保留，不当成成功快照复用。
- 同一新 helper 并行在 Android13／16 执行 QNS 持久化试验，两者均通过文件
  落盘、重新打开事务恢复、完整配置恢复、文件清理及重复恢复。独立 agent
  随后分别只读复核；本续批第二个 agent 受会话名额限制，因此最后复核顺序执行。
- 12 项解析契约和 21 项结果／旧报告防误报契约通过；修复末尾空行被 split
  丢弃的问题。按版本保存不含 SIM 身份／短信正文的结果与 helper 摘要。
- 仅新增配置事务层；现代安装器、守护恢复与应用入口尚未完成。已有原 XML、
  真正重启／杀进程恢复、真实运营商通话短信及双活动 SIM 仍未由此验证。
  三个现代服务 APK 未重建，当前 API30 手机未改动，来源和许可证继续保留。

详见 [事务说明](controller/README.md) 与 [本批结果](runtime/reports/20261006-persistence/matrix.json)。

## 续批：已有覆盖文件恢复与正式命令后端

- 新增所有已配置 modem 的通话空闲检查，覆盖空卡槽，缺失／重复／未知状态
  一律拒绝定向重载；13 项解析契约通过。

  无需 kill 电话进程；仍比较完整原配置，而非只比较四个服务字段。
- 修复准备基线的完整性条件：AOSP 保存时会把内部包版本字段写入 RAM bundle，
  从文件读回时会去掉它。事务拒绝尚未从磁盘加载的这种基线；试验先从磁盘
  加载种入的原文件再快照，未放宽完整比较。
- Android13／16 并行完成六个独立 app_process 阶段，验证已有原 XML、文件
  恢复但内存未恢复时拒绝确认、模拟 FILE_RESTORING 中断后的续接、完整恢复、
  重复恢复、记录掩码核验、错误掩码拒绝及整个试验电话 PID 不变。未执行真杀
  进程或系统重启；最初失败与最终成功的结果分别保存。
- 新增 ModernCarrierController 正式 root 命令后端，供之后的协调器／应用接入。
